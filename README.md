# Feri Agent 🎧

دستیار صوتی هوشمند برای ایرپاد

وقتی به ایرپاد وصل باشی، کافیه بگی **«داداش؟»**

- 🎵 کنترل موزیک (بعدی / قبلی / ولوم)
- 📞 تماس با مخاطبین
- 🔊 پاسخ صوتی فارسی

## ویژگی‌ها
- اجرا در پس‌زمینه (Foreground Service)
- تشخیص اتصال بلوتوث (AirPods)
- تشخیص هات‌ورد «داداش؟»
- دستورات فارسی
- رابط کاربری مدرن با Jetpack Compose

## دستورات پشتیبانی‌شده
| دستور | عملکرد |
|-------|--------|
| داداش؟ | فعال‌سازی حالت شنیدن |
| موزیک بعدی / برو جلو | ترک بعدی |
| موزیک قبلی | ترک قبلی |
| ولوم رو زیاد کن / کم کن | تنظیم صدا |
| به [اسم] زنگ بزن | تماس با مخاطب |

## ساخت پروژه
```bash
./gradlew assembleDebug
```

APK در مسیر `app/build/outputs/apk/debug/` ساخته می‌شود.
